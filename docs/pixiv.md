# 发图指针（`[看图:…]`）

提示词里只留一句「要发图就写 `[看图:角色名 作品名]`」——**只告知有这个出口，不写规则**。
所有细节（拆词、译名、分级、冷却）都在代码里，改这些不需要碰提示词。

## 一、指针形态

```
[看图:流萤 崩坏星穹铁道]
[发图:芙宁娜]
[来张图:銀髪]
[看图:流萤 崩坏星穹铁道|ホタル(スターレイル)]     ← 多候选，| 、 空格都算分隔
```

- 捕获组 1–40 字，取前 30 字用
- 模型只写指针没写正文 → 自动补「喏，这张」
- 指针被抽走后若剩空文本、且没拿到图 → 这一条就不发
- 未闭合的 `[看图:xxx` 有两种兜底正则清理，绝不会漏进群
- 一句话最多一张图：拿到 pixiv 图就把表情包和画图请求压掉

## 二、pixiv 多词条 = AND，这是所有坑的源头

实测（`s_mode=s_tag`，`mode=safe`）：

| 搜索词 | 结果数 |
|---|---|
| 流萤 | 15433 |
| 崩坏星穹铁道 流萤 | 12352 |
| 崩坏星穹铁道 流萤 **站姿** | **0** |
| 流萤 站姿 / 流萤 立ち姿 | **0** |
| 芙宁娜 | 31672 |
| 銀髪 / 银发 | 132004 / 134432 |

**每多一个 pixiv 上不存在的 tag，就直接 0 条。** 「站姿」「立ち姿」都不是 tag，
`银发 少女` 能出（864 条）纯属两个都是真 tag。

`s_mode=s_tag_full`（标题+简介全文）也救不了 `流萤 站姿`（同样 0 条），所以没有采用。

## 三、降级链（`search_ids`）

按顺序试，任一段拿到就收工：

1. **拆词**（`word_variants`）：从右往左砍修饰词，最后单拎每个词
   - `崩坏星穹铁道 流萤 站姿` → `崩坏星穹铁道 流萤 站姿` / `崩坏星穹铁道 流萤` / `崩坏星穹铁道` / `流萤`
   - 中文不空格按「的」拆一次：`流萤的站姿` → `流萤` / `站姿`
   - `|` `、` `，` 是「多候选」分隔，各候选互不相干，不会把整串拿去 AND：
     `流萤 崩坏星穹铁道|ホタル(スターレイル)` → `流萤 崩坏星穹铁道` / `流萤` / `崩坏星穹铁道` / `ホタル(スターレイル)`
   - 最多 5 个候选，命中会打日志 `拆词搜到（用的「X」）`
2. **换排序**：`popular_d` → `date_d`（popular_d 配中文 tag 偶尔返回空页）
3. **译名**：`/ajax/search/tags/<词>` 的 `tagTranslation` 拿 `en` / `romaji` 再搜
4. **放开服务端分级**：`mode=all` + 本地严格过闸（闸一道没少）

再全空 → 只发文字，不报错、不解释。

## 四、R18 闸（三步，缺一不可）

只信 pixiv 官方字段，不信作者自填 tag：

- `xRestrict == 0`（1=R18，2=R18G）
- `sl == 2`（4=成人向）
- 列表 tag 与**详情页 tag 各查一遍**黑名单（列表接口的 tag 常被截断）：
  `r-18` `r18` `r-18g` `r18g` `グロ` `エロ` `guro` `nsfw` `adult` `18禁`
- `illustType == 2`（动图）直接跳过，转录要转码，不值当

账号开了 R18 显示照样拦得住：返回里混着成人作品是常态，靠的永远是这三步而不是搜索参数。

## 五、取图细节

- 搜索：`/ajax/search/artworks/{quote(词)}?word=…&order=popular_d&mode=safe&p=1&s_mode=s_tag&type=all&lang=zh`
- 详情：`/ajax/illust/{id}` → `urls.original`
- 原图 > 4MB 退 `urls.regular`（1200px）；原图动辄十几 MB，QQ 发不出去
- `i.pximg.net` **必须带 `Referer: https://www.pixiv.net/`**，否则 403
- 国内必须过代理（`pixiv_proxy`，默认 7890）
- 最多换 3 个作品试，详情失败 / 图片 404 / 超体积都会换下一张

## 六、Cookie

fish 的 `pixiv_cookie` 留空时自动读 `data/config/astrbot_plugin_media_parser_config.json`
里的 `pixiv.cookie`，两处存一份就行。

找路径是**从 main.py 逐级往上找 `config/astrbot_plugin_media_parser_config.json`**，
不要写死 `parents[2]`——开发目录和部署目录层级不同，写死会表现为「本地测没 cookie」。

## 七、冷却

同一个标签 600 秒内不重复搜。pixiv 有频率限制，429 一次之后整段时间都发不出图。

## 八、群里「没反应」怎么查

按这个顺序看日志，别一上来就怀疑提示词：

1. 有没有 `[fish] 模型要发图，标签「X」` → 没有 = 模型没吐指针（跟取图无关）
2. 有没有 `[fish] pixiv 搜「X」：N 条结果` → N=0 = 词搜不到（看有没有 `拆词搜到`）
3. 有没有 `全年龄 M 条` 且 M=0 → 全被分级闸掉
4. 有没有 `pixiv 发图：标签「X」→ <id>` → 到这里就成功了
